- Velozes e Furiosos (2001) | Meu filme favorito

Site de uma página sobre o filme **Velozes e Furiosos** (*The Fast and the Furious*, 2001), feito como trabalho escolar para praticar HTML e CSS.

-Linguagens

- HTML5 com tags semânticas
- CSS3

- Conteúdo da página

- **Sinopse:** resumo da história, com uma citação do filme
- **Personagens:** lista dos principais personagens e seus atores
- **Carros:** os carros mais marcantes do filme
- **Ficha técnica:** tabela com título original, ano, direção, gênero, país e elenco

- O que foi aplicado

- Tags semânticas: `header`, `nav`, `main`, `section`, `figure`, `figcaption`, `blockquote`, `table` e `footer`
- Tabela acessível, com `caption` e `th scope`
- Acessibilidade: atributo `lang`, texto alternativo (`alt`) nas imagens e `aria-label` no menu
- Menu com links internos (âncoras) para cada seção
- Cores e medidas centralizadas em variáveis CSS (`:root`)
- Enquadramento das fotos com `object-fit` e `object-position`
